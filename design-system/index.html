완등 한 컷

실제 서비스 UI를 기준으로 정리한 디자인 시스템

공통 스크롤 정책: 모든 화면·입력·패널에서 가로/세로 스크롤바를 숨기며 스크롤바 공간을 예약하지 않습니다. 스크롤 동작은 유지합니다. static/shared/scrollbars.css를 공통으로 사용합니다.

서비스에서 사용 중인 구성 요소를 불러오는 중이에요.

컬러 시스템

원티드 Montage의 Atomic → Semantic 구조를 바탕으로 완등 한 컷에 맞춘 컬러입니다. 블랙을 중심으로 회색 단계와 용도별 색상을 정리했습니다.

기준: Wanted Montage · Atomic Colors · 2026.11.08 확인 · 아래 값은 v2 서비스와 같은 공통 스타일 파일에서 읽습니다. 기존 v1 원본 예제는 원본 스타일을 유지합니다.

사용 원칙

  • 기본 팔레트(Atomic)는 색상 단계, 용도별 색상(Semantic)은 실제 사용 역할을 정의합니다.
  • 주요 버튼과 선택 텍스트는 블랙, 배경과 구분선은 회색 위계를 사용합니다.
  • 빨간색은 삭제·오류에 사용합니다. 남은 기간에는 추가 상태색을 적용하지 않습니다.
  • 암장별 로고·레벨 컬러·사용자가 만드는 썸네일 색상은 별도로 유지합니다.
  • 기존 유리 메뉴의 투명도·그림자·흐림과 서비스 구성 요소의 크기·동작은 유지합니다.
