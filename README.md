# 완등 한 컷

현재 정식 버전은 **v1.2.0 (`site-v1.2.0`)**이며, 한컷체 **1.005 (`font-v1.0.5`)**를 사용합니다.

[웹페이지 열기](https://choeziwon.github.io/climbing-thumbnail-site/)

한컷체를 포함한 9종 폰트와 다양한 도형으로 클라이밍 썸네일을 만드는 정적 웹페이지입니다. 이미지는 브라우저 안에서 처리되며 서버로 업로드되지 않습니다.

이 저장소에는 공개 배포에 필요한 HTML·JavaScript·CSS와 폰트 파일만 포함됩니다. 각 폰트의 라이선스는 HTML의 fontLicenses 항목과 `assets/licenses/`에 포함되어 있습니다. 한컷체의 조건은 `assets/OneKut-LICENSE.txt`에서 확인할 수 있습니다.

## 모바일 / 데스크톱 분리

- [데스크톱 버전](https://choeziwon.github.io/climbing-thumbnail-site/desktop/) — `desktop/index.html`
- [모바일 버전](https://choeziwon.github.io/climbing-thumbnail-site/mobile/) — `mobile/index.html`, `mobile/editor.css`, `mobile/editor.js`
- 공통 편집·저장 기능 및 스타일 — `shared/`
- 공통 폰트·공유 이미지 — `assets/`

기존 루트 주소는 처음 접속할 때 화면 너비가 1080px 미만이면 모바일로, 그 외에는 데스크톱으로 연결됩니다. `/desktop/` 주소도 1080px 미만에서 열면 모바일로 연결됩니다. `/mobile/`은 모바일 화면을 유지합니다. 반응형 미리보기에서 명시적으로 데스크톱을 고른 경우에만 `?view=desktop`으로 해당 화면을 유지합니다. 데스크톱은 모바일 전용 코드를 로드하지 않습니다. 공유용 OG 및 canonical 주소는 기존 루트를 유지합니다.

## 웹 폰트 파일 이름

웹 폰트는 한컷체와 요청한 추가 8종을 제공합니다. 읽을 수 있는 폰트명으로 파일을 저장하며, 처음 접속할 때는 기본 한컷체만 로드합니다. CSS URL의 `?v=` 값으로 폰트 변경 시 캐시를 갱신합니다.

설치용 파일과 이용 조건: [한컷체 다운로드](https://github.com/choeziwon/climbing-thumbnail-site/releases/tag/font-v1.0.5). 제작자는 **원이네 스튜디오**이며 개인·기업의 상업적 이용까지 무료인 **한컷체 · OneKut 무료 이용 라이선스 1.0**을 적용합니다.

현재 1.005 배포본은 앱·웹 임베딩과 상업적 이용을 무료로 허용합니다. 폰트 수정·별도 재배포·폰트 자체 판매는 사전 허락이 필요합니다. [전체 라이선스](https://choeziwon.github.io/climbing-thumbnail-site/assets/OneKut-LICENSE.txt)를 확인하세요. 이전 OFL 배포본의 권한은 유지되며 이번 변경이 소급 적용되지 않습니다.

## 한컷체 1.005

최종 승인한 25안입니다. 초성 ㅇ의 조합별 비례, ㅎ·ㅊ 윗획, ㅋ의 두 번째 획과 종성 ㄲ·ㅆ 두께를 보강하고 종성 ㅎ을 10% 확대했습니다. 현대 한글 11,172자의 조합 출력과 윤곽 범위를 검사했습니다. 모바일과 데스크톱에 같은 한컷체 배포본을 적용합니다.

## v1.1.0 — 사진 조정 (2026-10-20)

- 사진을 등록한 뒤 **사진 조정**에서 드래그로 구도를 옮기고 슬라이더나 모바일 두 손가락으로 최대 4배 확대할 수 있습니다. 적용한 구도는 미리보기와 저장 PNG에 동일하게 반영됩니다. 취소하면 기존 구도를 유지합니다.
- 글자 크기를 최대 **500px**까지 조절할 수 있습니다. 처음과 초기화 후에는 문구가 비어 있고 입력창에만 안내 문구를 표시합니다. 안내 문구는 결과 이미지에 포함되지 않습니다.
- 성공 문제에 **핑크색**을 갈색 바로 뒤에 추가했습니다. 모바일과 데스크톱에서 같은 색상을 제공합니다.

## v1.1.1 — 공유 썸네일 (2026-10-20)

공유 썸네일에 흰색·핑크색 홀드를 추가해 위아래 여섯 개씩 총 12색으로 배치했습니다. 핑크색은 갈색 다음, 흰색은 회색 다음이며 공유 이미지 URL과 대체 텍스트도 갱신했습니다.

## v1.1.2 — 모바일 미리보기 확대 (2026-10-20)

모바일 사진 미리보기의 높이 제한을 없애 화면 너비에 맞춰 크게 표시합니다. 사진과 편집 항목을 함께 세로 스크롤하며 저장·초기화 헤더와 편집 탭은 스크롤 중에도 접근할 수 있습니다. 데스크톱 배치는 유지합니다.

## v1.2.0 — 모바일 편집 패널 접기 (2026-10-20)

모바일 편집 탭 옆 **접기** 버튼으로 옵션을 숨기고 사진을 화면 안에서 최대한 크게 볼 수 있습니다. 사진의 비율과 전체 구도를 유지하며 하단 탭 또는 **펼치기**로 다시 편집합니다. 접은 상태에서도 저장·초기화와 오류 안내를 사용할 수 있습니다.
